# 来源接口

/pipes 列出管段的两个端点和默认开闭状态。/switches 列出覆盖默认值的时段，只有 confirmed 为真时改变该时段的拓扑。同一管段在重合时间收到了同等级的相反确认时，两个版本都可能成立。/meters 的 site 和 point 共同标识门户内的测点，tap 为生效区间内的接入端。
/readings/{site}?from=&to= 按分钟取各测点记录。返回 coveredUntil 说明已经扫描到的时间边界，nextFrom 为空时本次所需时间已扫完。接口按来源设定最大连续扫描分钟数，边界处固定使用左闭右开，coveredUntil 之后的读数不属于本次响应。覆盖与异常以逐分钟有效记录判断。每个请求子段需要在指定管段的每个接入端找到至少一个可沿当时连通的管段到达的有效测点，且请求标出的隔离管段不能用于该证据路径。受冲突切换影响的可能路径只可作待核实依据。压力范围由调用方给出，闭区间内为正常。/field-returns 给出现场班组的补测回传。order、zone、端点与时间范围用于对应原补测单，记录仍需以现场测点的接入有效期和实际拓扑判断能否支持原请求。带班输入中的 issuedOrders 为已经交接的补测单。
